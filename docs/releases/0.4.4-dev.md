**Steam pitch scaling now works both ways:** smaller boilers pitch sounds up and larger boilers pitch them down, compared with the locomotive supplying the sounds. Diesel scaling also works both ways, using empty locomotive mass.

Both settings groups now show **lower pitch cap, upper pitch cap and effect strength** as percentages. Steam has a new upper cap, defaulting to 200%. Existing settings are preserved.

The log now records the first completed pitch adjustment for each discovered locomotive, making actual changes easier to check.

Close Derail Valley and UMM before updating. This is a development release.
