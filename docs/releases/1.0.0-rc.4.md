# Dad's Toolbox 1.0.0-rc.4

Adds **Chuff Fix**, with its own switch for native steam exhaust timing, short recording banks and recognised running loops. It supports vanilla and CCL locomotives without locomotive-specific rules.

Sound Pitch keeps other sound groups working while Chuff Fix controls rhythmic loop timing. Existing preferences are preserved.

Doppler pitch stays aligned when a running loop changes sample rate.

Remove standalone MultiCylinderChuffFix and restart before using the integrated feature. This candidate still needs final listening tests in the game.
