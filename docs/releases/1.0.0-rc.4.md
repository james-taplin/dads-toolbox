# Dad's Toolbox 1.0.0-rc.4

The first public 1.0 release candidate combines eight feature groups with nine independent switches in Unity Mod Manager.

### Included

- Chuff Fix and Bogie Visual Smoothing for vanilla and CCL stock.
- CCL smoke and control repairs, plus separate steam/diesel sound-pitch strength and limits.
- HUD Guard, Skin Manager scorch protection and embedded-skin registration.
- DoubleTrack sign clearance with adjustable clearance and movement limits.

Chuff Fix preserves native rhythmic-loop cadence alongside Sound Pitch. Sound/control discovery work has been reduced, and sign clearance distinguishes tracks on separate levels.

### Install

Close the game and install `DadsToolbox-1.0.0-rc.4-Nexus.zip` through UMM. Remove standalone copies of the included fixes, keep their required mods, and restart. Keep Toolbox's `Settings.xml` when updating to preserve preferences.

The download contains only the DLL, UMM metadata and MIT licence notice. See the [user guide](https://github.com/james-taplin/dads-toolbox/blob/main/docs/README.md) for dependencies and restart behaviour. Loco Sound Pitch is incompatible with ZSounds.

Offline checks and in-game testing support this public RC. Locomotive/mod coverage varies; multiplayer compatibility is not established. Please include `Player.log`, versions and reproduction steps with reports.
