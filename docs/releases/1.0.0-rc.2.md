# Dad's Toolbox 1.0.0-rc.2

Adds **Bogie Visual Smoothing** as an independent switch. It smooths visual copies of bogies while keeping native physics, steering and wheel/rod animation. Vanilla and CCL vehicles use the same component-based implementation.

Close the game and move the standalone DVLocoBogieVisuals folder outside Mods before using the Toolbox copy. Keep it as a fallback. Toolbox stays inactive for this feature if the standalone is still loaded. Bogie Edge Diagnostic Probe remains separate.

Keep your Toolbox Settings.xml when updating. Other fixes retain their own switches and settings.
