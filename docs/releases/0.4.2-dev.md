Embedded-skin registration now supports **CCL 3.1.9 and newer**, including 3.1.11. The correction is still needed on 3.1.11 to help skins bundled with vehicles load correctly. Compatibility checks remain in place; Skin Manager 4.4.1 is required.

Existing settings are preserved. No other fixes changed.

Close Derail Valley and UMM before updating, and keep your Toolbox Settings.xml. This is a development release.
