# Dad's Toolbox 1.0.0-rc.1

A release candidate combining HUD Guard, CCL Control Fix, Loco Sound Pitch, two Skin Manager fixes, CCL Smoke Fix and DoubleTrack sign clearance. Each fix has its own switch in Unity Mod Manager.

This candidate improves sign clearance at bridges and underpasses, reduces repeated sound-discovery and control-input work, and cleans up sound diagnostics after vehicles despawn.

Close the game before installation. Keep your Toolbox Settings.xml when updating, and disable matching standalone fixes. See the user guide for dependencies and restart behaviour.
