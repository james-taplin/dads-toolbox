The first combined development release of Dad's Toolbox, with independent switches for:

- HUD Guard
- CCL Control Fix
- Loco Sound Pitch
- Skin Manager scorch protection and embedded-skin registration
- CCL Smoke Fix
- DoubleTrack sign clearance
- H6F Consist Fix (removed in 0.4.1-dev following the developer's repair)

Install through Unity Mod Manager with the game closed. Disable matching standalone fixes and preserve SteamSizePitch settings before migrating. See the [installation guide](https://github.com/james-taplin/dads-toolbox/blob/main/docs/README.md#switching-from-standalone-fixes).

This is a development release; [a newer version is available](https://github.com/james-taplin/dads-toolbox/releases/tag/0.4.2-dev).
