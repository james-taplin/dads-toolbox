Dad's Toolbox 0.4.0-dev combines seven optional feature groups in one Unity Mod Manager mod, with eight independent switches:

- HUD Guard.
- Consist Fix (currently H6F only).
- CCL Control Fix.
- Loco Sound Pitch for CCL steam and non-steam native exterior audio.
- Skin Manager scorch protection and embedded-skin registration.
- CCL Smoke Fix.
- DoubleTrack sign clearance.

Dependencies remain optional; statuses explain absent/inactive/incompatible dependencies or duplicate standalone fixes. Each patching feature has its own explicit Harmony owner and targets. Shared settings preserve desired choices independently of effective operation.

**Migration:** close Derail Valley and disable/remove the superseded standalone CCLSmokeFix, DVCCLControlFix, SteamSizePitch, DoubleTrackSignClearance and DVRollingStockCompatibility before a cold restart. Keep the actual CCL, HeadsUpDisplay, Skin Manager, DoubleTrack and H6F mods. Preserve/migrate SteamSizePitch/Settings.xml before removing its folder; the automatic one-time importer reads that sibling file. ZSounds is incompatible with sound pitch.

Controlled native Unity/UMM/Harmony fixtures exercise lifecycle, cleanup, ownership, settings migration and native APIs. This is a development prerelease: actual game boot/import/spawn, real controls/Rewired/prefab acceptance, listening/performance, rendered smoke, streaming, explosion/repair and save/reload remain pending. The existing companion paint-data workaround remains supported.
